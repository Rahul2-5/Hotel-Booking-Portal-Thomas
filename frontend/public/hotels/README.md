# Optional hotel photographs
Place your own photo here named after the hotel id: `1.jpg`, `2.webp`, etc.
Supported extensions: jpg, jpeg, png, webp, avif. Use one photo per id.
Restart Vite after adding a file; production builds include files present at build time.
Without a photo, the UI shows a deterministic CSS cover with the hotel city.
Only use photographs you own or have permission to publish.
